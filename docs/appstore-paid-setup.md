# 有料App契約・銀行口座・税務情報の登録手順

買い切り課金「VitaNote Pro」(¥480 / ROADMAP の D-0) を出すために必要な、
App Store Connect 側の契約手続きをまとめる。

**TestFlight 配布(C-5)と無料アプリの公開には不要。** 課金を実装する前に
済んでいればよいが、銀行口座の確認や契約の反映に数日かかることがあるため、
早めに着手しておくと D-0 で待たされない。

> Apple は画面構成をよく変える。ここに書いた項目名が見当たらない場合は、
> 画面の指示を優先すること。

---

## 0. 前提

- **Account Holder(アカウント保持者)本人**でないと操作できない。VitaNote は
  個人アカウントなので、あなた自身でサインインする
- 個人アカウントのため、法的名称(Legal Entity)は**本名**になる

### 先に確認しておきたいこと

- [ ] **App Store 上の販売者名** — 個人アカウントでは本名が表示される。
      屋号やペンネームで出したい場合は別途手続き(または法人アカウント)が
      必要になるため、公開前に何が表示されるか必ず確認する
- [ ] **勤務先の副業規定** — 収益が発生するため、届出の要否を確認しておく
- [ ] **確定申告の扱い** — 金額が読めてきた段階で確認する

---

## 1. 有料Appに関する契約を締結する

1. https://appstoreconnect.apple.com にサインイン
2. **契約/税金/口座情報** を開く
3. 「有料App」の契約について **リクエスト / 同意** する
4. 同意すると、ステータスが「アクションが必要」に変わる。
   以降の手順(連絡先・銀行口座・税務情報)をすべて埋めると「有効」になる

この契約が **「有効」になるまで、アプリ内課金アイテムを提出できない**。
D-0 の実装より前に通しておく。

---

## 2. 連絡先情報を設定する

契約画面の「連絡先情報」で、以下の担当者を設定する。個人開発なので
すべて自分を指定してよい。

- 上級者(Senior)
- 財務(Financial)
- 技術(Technical)
- 法務(Legal)

住所・電話番号はローマ字/半角で入力する欄がある。

---

## 3. 銀行口座を登録する

「銀行口座」から追加する。日本の銀行でよい。

用意するもの:

| 項目 | 補足 |
|---|---|
| 銀行名・支店名(支店コード) | |
| 口座種別 | 普通 / 当座 |
| 口座番号 | |
| 口座名義 | **ローマ字(半角英字)**。通帳やキャッシュカードの英字表記と一致させる |
| 通貨 | JPY |

**つまずきやすい点**

- 名義の表記ゆれで弾かれることがある。銀行側の登録(英字名義)と
  一字一句合わせる
- 売上は毎月まとめて支払われるが、**最低支払金額のしきい値**があり、
  達しない月は繰り越される。金額は契約書・画面表示で確認すること
- ネット銀行でも登録できることが多いが、対応可否は画面の指示に従う

---

## 4. 税務情報を登録する

「税金」から、求められるフォームを埋める。日本在住の個人なら
少なくとも米国と日本のフォームが出る。

### 米国税務フォーム(W-8BEN)

米国以外の居住者である個人が提出するフォーム。**法人ではなく個人**なので
W-8BEN-E ではなく W-8BEN を選ぶ。

- 氏名・住所はローマ字
- 居住国: 日本
- **外国の納税者番号(Foreign TIN)** の欄がある
- **日米租税条約の適用を必ず申告する** — 使用料(Royalties)に対する
  源泉徴収の軽減を受けるための欄。ここを埋めないと米国での売上に対して
  **30% 源泉徴収される**。条約を適用すれば軽減される

> 租税条約の条項番号・税率、および Foreign TIN に何を書くかは、
> 画面の説明と最新の条約内容を確認して記入すること。ここは金額に
> 直結するので、不明なら税理士に確認するのが安全。

### 日本の税務フォーム

画面の指示に従って入力する。インボイス制度の登録番号など、
時期によって追加の入力を求められることがある。

---

## 5. ステータスが「有効」になったことを確認する

「契約/税金/口座情報」で、有料Appの契約が **有効(Active)** と表示されれば完了。
この状態になってから、D-0 のアプリ内課金アイテムを作成する。

---

## 6. その後の維持

- Apple が規約を改定すると **再同意が必要**になる。同意しないまま放置すると
  有料アプリの配信が止まるため、App Store Connect からの通知メールは
  見落とさないこと
- 銀行口座を変えたときは、この画面で更新する
