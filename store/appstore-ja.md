朝いちばんの体重、飲んだお薬のチェック、健診でもらった検査結果。
別々のアプリに散らばりがちな記録を、手帳に書くように1か所へ書き込めます。
アカウント登録はありません。広告もありません。書いたものはすべて、あなたのiPhoneの中だけに保存されます。

■ 毎日の記録
・体重、体脂肪率、腹囲

・飲水量、運動
・歩数(iPhoneのヘルスケアから自動で取り込み。1時間ごとの内訳も)

■ お薬のチェック
・朝昼夕・間食それぞれに、飲んだかどうかのチェック
・食前/食後、週1回(曜日指定)、月1回(日にち指定)のお薬にも対応
・お薬は日をまたいで引き継がれるので、毎日入力し直す必要はありません

■ 開いたら終わっている
歩数は自動で入り、体重は1タップ。1日の記録は10秒ほどで終わります。
記録がまだない時間に通知でお知らせします(記録済みの日は鳴りません)。

■ 振り返る
・体重と腹囲を重ねた折れ線、体脂肪率、摂取カロリー、歩数のグラフ
・「カロリー貯金」= その日に使ったカロリー − 食べたカロリー。
　貯金が約7,200kcalたまるごとに体重が1kg減る計算です
・1か月を1日1行で見渡すカレンダー。その日のメモも一緒に残せます

■ 書く楽しさ
方眼紙の紙面と朱色のスタンプ。記録用紙ではなく、手帳として使えるように仕上げました。

■ SelfCareNote Pro(買い切り)

・血圧・血糖値の記録とグラフ
一度購入すれば期限はありません。購入しなくても、体重・食事・歩数・お薬の記録はすべてお使いいただけます。

アカウントもクラウドもありません。記録はすべて端末内に保存され、外部のサーバーへ送信されることはありません。
そのぶん、端末を初期化するとデータも失われます。機種変更のときはiCloudバックアップから復元してください。

■ つくった人
薬剤師の資格を持ちながらエンジニアとして働いている開発者が、家族のためにつくりました。
お薬の効き目や飲み合わせについての助言は行いません。記録のためのアプリです。

※本アプリは記録が主目的であり、病気の診断・治療・予防を目的としたものではありません。
　数値の見方や体調については、医師・薬剤師にご相談ください。

## スクリーンショット

App Store Connect が必須にしているのは最大サイズ(6.9インチ)のみで、
小さい画面には自動で流用される。実機で撮る。5枚。

撮る前に、見栄えのするダミーではなく**実際に使っている記録**を1〜2か月ぶん
入れておくこと。空のグラフは何も伝えない。

**組み上がりは store/screenshots/ にある(2026-08-01作成、5枚とも1320x2868)。**
作り直すには `node store/make-screenshots.mjs`。元の実機スクリーンショットは
photo/ に置く(.gitignore対象・手元のみ)。

| # | 画面 | 添えるキャプション |
|---|---|---|
| 1 | 「きょう」タブ(貯金・処方箋・体重・食事) | 体重とお薬を、1冊にまとめて |
| 2 | 食事とお薬のチェック(朝昼夕が並んだ状態) | 飲んだかどうかを、その場で |
| 3 | 「ふりかえり」の体重・腹囲グラフ(1か月ぶん) | 続けた分だけ、線になる |
| 4 | 「カレンダー」タブ(歩数とメモが並んだ月表) | 1か月を、1日1行で見渡す |
| 5 | 「ふりかえり」の血液検査の表 | 健診の数値も、同じ手帳に |

- 1枚目が一番見られる。タブバーまで含めてアプリの全体像が分かる画面にする
- ステータスバー(時刻・電池)は組み立て時に切り落としている。アプリの中身だけを見せる

## D-2 プライバシーラベル(App のプライバシー)

App Store Connect でアプリごとに答える質問票のこと。答えた内容が、
App Store の製品ページに「Appのプライバシー」として表示される。
**日本語では「Appのプライバシー」、英語だと Privacy Nutrition Label。**

### 入力する場所と手順

1. App Store Connect → 対象アプリ → 左メニュー **「Appのプライバシー」**
2. プライバシーポリシーURL に https://tsukune131.github.io/VitaNote/legal/privacy.html
3. 「データ収集」の質問で **「いいえ、このAppではユーザーからデータを収集しません」**
4. 保存して「公開」。審査提出前に入力が済んでいないと提出できない

**入力済み(2026-08-01)。**

### 回答: 「データを収集していません」

根拠:
- アカウント登録なし、サーバーへの送信なし。記録はすべて端末内(IndexedDB)
- 解析・広告SDKなし。エラー監視(Sentry)は 2026-08-01 に依存ごと撤去済み
- HealthKit から読む歩数、書き戻す体重・体脂肪率は端末内で完結する
- App内課金の決済は Apple が扱う。開発者側は購入情報を受け取らない

> 「収集」= 開発者の管理下(サーバー等)へデータを移すこと。端末内に留まる
> 記録は収集に当たらない。この構成を変えたら申告も変える。

**判断はアプリ本体だけでなく、組み込んだSDKも含めて行う必要がある。**
現在の依存はCapacitorのプラグイン(ヘルスケア・通知・触覚・スプラッシュ・課金)
だけで、いずれも開発者へデータを送らない。解析SDKを1つ入れた時点で
この申告は嘘になるので、依存を足すときは必ずここに戻ること。

### あわせて確認

- [ ] TestFlightへのアップロード後にAppleから届くメールに、プライバシー
      マニフェスト(PrivacyInfo.xcprivacy)関連の警告が無いか。アプリ本体には
      置いていないが、必要なAPIを使うプラグイン側は自分のマニフェストを
      同梱している。警告が来ていれば、その指示に従って追加する

### 年齢制限レーティング

医療・治療情報を提供するアプリではない(記録のみで助言をしない)ため、
該当項目は「なし」で回答する想定。質問文が変わっていたら画面の指示を優先。

審査担当者が購入画面に辿り着くためのもの。

### スクリーンショット(必須・1枚)

購入シートの実機スクリーンショットを1枚。加工は不要で、ストア用のような
寸法の縛りもない(640x920以上あればよい)。

撮る画面: 「設定」タブ →「SelfCareNote Pro」→「くわしく見る」
写っていてほしいもの: **価格の入った購入ボタン**と**「購入を復元」**。

> 価格が ¥500 と出ているビルドで撮ること。ドル表示のまま添付すると、
> 日本の価格設定と食い違って見え、余計な確認を招く。

## 提出前チェック(2026-08-02実施)

審査で落ちやすい点を通しで確認した結果。

| 見る点 | 状態 |
|---|---|
| 購入の復元ボタン | あり(購入シートと設定タブの2か所。購入後も残る) |
| アプリ内での価格表示 | あり(StoreKitの整形済み文字列。価格が取れないうちは購入ボタンを押せない) |

| 課金の外部誘導 | なし(決済はStoreKitのみ。外部の決済ページへのリンクなし) |
| アカウント削除の要件(5.1.1) | 対象外(アカウント作成の仕組みがない) |
| HealthKitの用途説明(Info.plist) | 実装と一致。広告・第三者提供に使わない旨をプライバシーポリシー4項に明記 |
| 通知 | ローカル通知のみ。外部送信なし |
| 医療機器該当性 | 規約1・2項で「記録のみ、診断・治療・予防を目的としない」と明示。
「きょうの処方箋」は名称の由来まで規約2項で説明済み |
| 「お薬手帳」の扱い | 規約3項で代替ではないと明示。キーワードにも入れていない |
| デバッグ表示・console出力 | なし |

  支払いの話が書かれていないのは穴だった
- プライバシーポリシーに決済の扱いを1行追加(開発者は氏名・支払い情報を受け取らない)
- 法務文書2通の最終改定日を 2026-08-02 に更新
